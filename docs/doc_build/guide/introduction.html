#介绍

SevenDesign 是一个企业级的 React UI 组件库，采用 TypeScript 开发，提供现代化、可定制的组件集合。

#特性

#🎨 精美设计

  • 现代化的设计风格
  • 参考 Element Plus 的设计理念
  • 提供优雅的用户体验

#📦 丰富组件

  • 基础组件：Button、Icon、Typography 等
  • 表单组件：Input、Switch、Select、Form 等
  • 布局组件：Flex、Space、Divider 等
  • 反馈组件：Message、Modal 等

#🔧 TypeScript

  • 完整的类型定义
  • 更好的开发体验
  • 智能代码提示

#🎭 主题定制

  • 基于 CSS Variables
  • 轻松定制主题
  • 支持暗色模式

#⚡ 高性能

  • 按需加载
  • Tree-shaking 支持
  • 优化的打包体积

#兼容性

  • React >= 18.0.0
  • Modern Browsers (Chrome, Firefox, Safari, Edge)
  • 支持服务端渲染 (SSR)

#开源协议

SevenDesign 使用 MIT 开源协议。
